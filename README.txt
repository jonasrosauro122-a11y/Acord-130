ACORD 130 Workers Compensation Simulator

How to use:
1. Open index.html in any browser.
2. Enter VA name and email.
3. Complete Scenario 1 and submit for grading.
4. Scenario 2 unlocks only after Scenario 1 is passed.
5. Each scenario allows 3 failed takes. Trainer reset code: LAVA2026.

Deployment:
- Upload the entire folder to GitHub.
- Deploy to Netlify as a static site.
- Build command: leave blank. Publish directory: / or the folder containing index.html.

Important:
This is a mock training simulator, not an official ACORD form. It uses localStorage only, so progress is per browser/device.
